# CurriculumLens

**AI-Based Syllabus Similarity Analysis and Curriculum Novelty Detection System**

CurriculumLens is a full-stack web application that uses supervised machine learning and NLP to analyze university syllabi, identify overlapping topics, and detect potentially new curriculum content.

---

## Features

| Feature | Description |
|---|---|
| Single Syllabus Analysis | Extract topics, visualize unit distribution, explore topic relationships in a force-directed graph |
| Two-Syllabus Comparison | Upload existing + proposed syllabus; classify each topic pair as Highly Similar, Partially Similar, or Unrelated |
| Novelty Detection | Identify topics in the proposed syllabus with no strong match in the existing one |
| Interactive Visualizations | Chart.js bar/doughnut charts, D3.js topic graph, D3.js heatmap |
| Model Performance Dashboard | Real evaluation metrics from the trained classifier (accuracy, macro-F1, confusion matrix) |
| Export Reports | Download analysis results as CSV or PDF |

---

## Technology Stack

- **Backend:** Python, Flask
- **ML:** scikit-learn (TF-IDF, Logistic Regression, Linear SVM)
- **Document Processing:** PyMuPDF (PDF), python-docx (DOCX)
- **Report Generation:** ReportLab (PDF), csv (CSV)
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js, D3.js
- **Testing:** pytest

## Dataset

- **Name:** `final_syllabus_similarity_dataset`
- **Size:** 900 labelled syllabus-section pairs
- **Splits:** Train 630 / Val 137 / Test 133
- **Classes:** `highly_similar` (300), `partially_similar` (300), `unrelated` (300)
- **Features used:** `text_a`, `text_b` only (no metadata leakage)
- **Data origin:** Synthetic — all examples authored for this project

## Usage

### Step 1 — Train the model

```bash
python train_model.py
```

This trains Logistic Regression and Linear SVM, selects the best by macro-F1 on the validation set, and saves the model to `models/`.

### Step 2 — Evaluate on the test set

```bash
python evaluate_model.py
```

Evaluates the selected model on the held-out test set and saves metrics to `evaluation/`.

### Step 3 — Start the web application

```bash
python app.py
```

Open your browser at: **http://localhost:5000**

- **DOCX** — Microsoft Word documents

Maximum upload size: 20 MB per file.

---

## Limitations

1. All training data is **synthetic**. Performance on real university syllabi must be validated separately.
2. TF-IDF cannot capture semantic equivalence across different terminology.
3. Scanned PDFs are not supported (no OCR in this version).
4. Topic extraction depends on consistent syllabus formatting.
5. Classifier confidence values are class probabilities — not literal syllabus overlap percentages.
6. "Potentially new" topics are new *relative to the existing syllabus*, not globally novel.

## Troubleshooting

**"Trained model not found"** — Run `python train_model.py` first.

**"No test evaluation found"** — Run `python evaluate_model.py` after training.

**"PDF extraction failed"** — Ensure the PDF is text-based, not a scanned image.

**"Very little text could be extracted"** — The document may be mostly images or have complex formatting.
