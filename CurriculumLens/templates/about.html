About CurriculumLens

AI-Based Syllabus Similarity Analysis and Curriculum Novelty Detection System

Problem Statement

Universities regularly need to compare syllabi across courses, departments, and academic years. Identifying overlapping topics, detecting curriculum gaps, and reviewing proposed curriculum changes manually is time-consuming — especially when similar concepts use different terminology across documents.

CurriculumLens automates parts of this process using Natural Language Processing and a supervised machine learning classifier trained on labelled syllabus-section pairs.

Project Objectives

  • Build a reproducible supervised learning pipeline for three-class syllabus similarity classification.
  • Implement practical syllabus segmentation that extracts units and topics from uploaded documents.
  • Provide single-syllabus analysis (topic extraction, clustering, relationship graph) without requiring a second document.
  • Provide two-syllabus comparison with per-topic pair classification and heatmap visualization.
  • Identify topics in a proposed syllabus that have no strong match in the existing syllabus.
  • Generate downloadable CSV and PDF reports.
  • Present evaluation metrics from actual model predictions — not hard-coded numbers.

Supervised Learning Approach

The classifier is trained on pairs of syllabus section texts (text_a, text_b) with three target labels:

  • highly_similar — Substantial overlap in concept, terminology, or learning outcome.
  • partially_similar — Shared themes but different in scope or depth.
  • unrelated — Distinct, non-overlapping content.

Pipeline:

  1. Normalize text (lowercase, unicode normalization, whitespace cleanup).
  2. Concatenate pairs: text_a + " [SEP] " + text_b.
  3. Vectorize using TF-IDF (word unigrams + bigrams, max 30,000 features, sublinear TF).
  4. Train Logistic Regression (multinomial, C=1.0) and Linear SVM (calibrated with 3-fold CV).
  5. Select model with higher macro-F1 on the validation set.
  6. Evaluate the selected model on the untouched test set.

Data leakage prevention: The TF-IDF vectorizer is fit only on training text. Only text_a and text_b are used as features.

Dataset

The primary dataset (final_syllabus_similarity_dataset) contains 900 synthetic labelled syllabus-section pairs.

  • Train: 630 examples · Validation: 137 · Test: 133
  • Balanced: 300 examples per class
  • Topic-family-disjoint splits (no topic families shared across train/val/test)
  • Data origin: synthetic — all examples authored specifically for this project
  • 9 topic batches across domains including HCI, NLP, Networks, Deep Learning, and more

Important: Good results on this synthetic benchmark do not prove equivalent performance on real university syllabi. Human review of borderline predictions is strongly recommended.

Limitations

  • TF-IDF operates on surface word forms. Semantically equivalent topics described with different vocabulary may score low similarity.
  • Scanned PDFs are not supported — only text-based PDFs are processed.
  • Topic extraction quality depends heavily on consistent syllabus formatting.
  • The classifier is trained on synthetic data. Real-world performance must be validated with annotated real syllabi.
  • Classifier probabilities are not literal syllabus overlap percentages.
  • Topics flagged as "potentially new" are new relative to the existing syllabus only — not globally novel.
  • The partially_similar class involves subjective judgment; borderline cases should be reviewed by domain experts.

Future Enhancements

  • Sentence-transformer embeddings (e.g. SBERT) for semantic rather than lexical similarity.
  • OCR support for scanned PDFs.
  • Active learning interface for borderline label correction.
  • Evaluation on real annotated university syllabi.
  • Batch processing for multiple syllabus pairs.
  • User-adjustable matching thresholds via UI.
  • LLM-based rationale generation for each predicted pair.
