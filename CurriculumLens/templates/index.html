What CurriculumLens Does

🔍

Single Syllabus Analysis

Upload one syllabus. Extract topics, explore unit distribution, and visualize topic relationships in an interactive graph — no second document needed.

⚖

Two-Syllabus Comparison

Upload an existing and a proposed syllabus. The trained classifier labels each topic pair as Highly Similar, Partially Similar, or Unrelated.

🆕

Novelty Detection

Identify topics in the proposed syllabus with no strong match in the existing one — flagged as "potentially new relative to the existing syllabus."

📊

Interactive Visualizations

Similarity distribution charts, topic relationship networks, heatmaps, unit distribution comparisons, and a detailed model performance dashboard.

🤖

Supervised ML Pipeline

Real TF-IDF + Logistic Regression / Linear SVM training on 900 labelled syllabus-section pairs. Model selected by macro-F1 on a held-out validation set.

📥

Downloadable Reports

Export analysis results as structured CSV or detailed PDF reports, including topic matching tables and interpretation notes.

Relationship Classes

HIGHLY SIMILAR

Two syllabus sections cover the same core concept, terminology, or learning outcome with substantial overlap.

e.g. "Usability evaluation using heuristic inspection" ↔ "Expert review against Nielsen's principles"
PARTIALLY SIMILAR

Two sections share related themes or sub-topics but differ in scope, depth, or specific focus areas.

e.g. "Machine learning basics" ↔ "Supervised classification algorithms"
UNRELATED

The two sections cover distinct, non-overlapping content — even if they are from the same general field.

e.g. "Network routing protocols" ↔ "Morphological text analysis"
